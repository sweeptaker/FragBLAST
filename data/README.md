# Input data

The full input FASTA files used for the analyses are not stored in this GitHub
repository because of their size.

- `IHSMGC.pep.gz`: human skin microbiome protein catalog.
- `IGC.pep`: integrated human gut microbiome gene catalog.
- `SARG.fasta`: Structured Antibiotic Resistance Genes database.
- `tara_ocean.fa`: amino acid sequences from the Tara Oceans expedition.

See the main [README](../README.md) for dataset references and analysis
parameters.
